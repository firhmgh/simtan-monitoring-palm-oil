Enterprise Decision Support System (DSS)

Monitoring Areal Tanaman Sawit Berbasis Spasial & Dual Neural Engine

Sistem Enterprise terintegrasi untuk pemantauan kesehatan TBM III di PTPN IV Regional I. Dilengkapi analisis biometrik allometrik PPKS, audit spasial GeoJSON per blok kebun, dan inferensi preskriptif otomatis via Google Gemini & Groq Cloud.

Buka Demo Interaktif SIMTAN Pilih Role Demo (Superadmin / Admin / User)
Mode Demo Statis Aktif 100% di GitHub Pages — Bebas dependensi server lokal!

GIS Spasial Interaktif

Visualisasi poligonal batas kebun dan blok TBM III menggunakan Leaflet.js dengan layer GeoJSON aman, heatmap kesehatan tanaman (IPHI), serta transparansi canvas orthophoto.

Dual Neural Engine (L1 & L2)

Sistem audit agronomi preskriptif dengan failover cerdas: Google Gemini (L1) sebagai mesin multimodal & Groq Qwen 27B (L2) sebagai high-speed failsafe tanpa menampilkan error ke user.

Role-Based Access & Audit Trail

Hierarki hak akses berjenjang (Superadmin, Admin, User/Manager) dengan pelacakan riwayat unggah data Excel sensus, impersonation mode, serta ekspor laporan PDF formal.
